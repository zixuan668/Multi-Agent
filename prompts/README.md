# 智能体提示词导航

[返回项目总览](../README.md) · [团队协作规范](../docs/team-collaboration.md)

1. [01 · 策略提示词](strategy/)：已有版本化提示词，当前策略模块使用 v1.4。
2. [02 · 创意提示词](creative/)：v1.1，生成事实有据的文案与视觉制作方案。
3. [03 · 评审提示词](evaluation/)：v1.1，独立评分、证据定位、反馈复核与信息澄清。

统一服务启动时冻结提示词文本和摘要；修改后需重启，新任务使用新配置快照。

各成员只维护自己模块的提示词，更新时同步实现使用的版本与回归测试。不要复制其他模块提示词后放在根目录，也不要在提示词中嵌入密钥或敏感用户数据。
