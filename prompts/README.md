# 智能体提示词导航

[返回项目总览](../README.md) · [团队协作规范](../docs/team-collaboration.md)

1. [01 · 策略提示词](strategy/)：当前使用 v1.10 决策生成与 v1.10-review 短审查；读取整理后的简报，分开选择、执行和创意任务，严重交付缺口可阻断；旧版本保留追溯。
2. [02 · 创意提示词](creative/)：待开发，先确认创意输入 / 输出契约。
3. [03 · 评估提示词](evaluation/)：待开发，先确认评估规则及输入 / 输出契约。

各成员只维护自己模块的提示词，更新时同步实现使用的版本与回归测试。不要复制其他模块提示词后放在根目录，也不要在提示词中嵌入密钥或敏感用户数据。
