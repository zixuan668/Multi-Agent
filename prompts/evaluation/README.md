# 03 · 评估提示词区

当前使用 `v1.2.txt`，模型输出五维评分、风险、可定位反馈、建议动作及明确确认已解决的历史反馈 ID；总分、事实风险否决、路由及最终版本由 C 代码决定。v1.2 要求简洁且可核对的理由，避免复述输入与重复建议；不省略严重问题。`v1.0.txt`、`v1.1.txt` 保留供旧记录核对。已解决状态另存于反馈状态表，原始轮次不改写。新任务使用 equal-weight-v2：平均分仍为五维等权，同时阻止未确认解决的历史严重问题被高分放行；旧 v1 任务按冻结规则回读。提示词和配置指纹进入任务非敏感配置版本。公共发布前由 A/B/C 复核内部候选协议。

提示词不得嵌入真实密钥、虚构评分或投放效果。职责及对接说明见 [03 评估智能体](../../docs/03-evaluation-agent.md)。
