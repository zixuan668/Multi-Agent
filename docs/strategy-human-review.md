# 策略质量人工复核记录模板

适用 AC-004、AC-005、AC-006。模型辅助检查、程序测试或策略侧交接通过都不能代替本表。

正式 50 例先由团队确认费用再运行，至少 48 例合法结果只是结构目标。每类固定前两例，共 10 例，由两人独立检查；有分歧由第三人复核。小样本检查全部样例，包括同产品资源对照。

## 每次复核记录

复制以下内容，每个样例、每位复核人单独填写，先独立判断再讨论。

```text
运行报告文件：
case_id / task_id：
策略 result_id / version：
模型 / 提示词版本 / 校验版本：
复核人 / 日期：

AC-004 事实与相关性：通过 / 不通过 / 无法判断
  卖点依据是否直接支持表述；受众、预算、周期、禁用渠道/内容是否遵守。
  引用具体字段及原文：

AC-005 渠道理由：通过 / 不通过 / 无法判断
  为什么适合该产品和目标；各渠道承担什么不同任务。
  引用具体字段及原文：

AC-006 产品差异：通过 / 不通过 / 无法判断
  产品、价格、入口、素材、人力改变后，内容选择是否有可解释变化。
  对照样例编号及具体差异：

执行性：可按现有资源执行 / 补充条件后执行 / 不可执行
  谁做、先做什么、用什么素材、受众下一步行动；缺口是否如实列出。

创意接续：可以直接制作 / 需要补问 / 无法接续
  一个传播重点、卖点证据、内容母题、渠道任务和不能说的内容是否清楚。

问题清单：字段路径 + 输出原文 + 违反的输入事实/约束或质量原因。
决策可读性：能否一句话说出优先解决什么、为何选它、暂不做什么。
目标一致性：触达新用户、解释信息与承接点单是否混淆；资源不足是否明确有限范围。
资源一致性：是否虚构执行人，或把已确认权限/素材反复列为未知。
去重：渠道、创意任务、执行步骤是否有分工，而不是复制同一句话。
最终意见：通过 / 修改后重检 / 等待补充资料。
第三人复核（有分歧时）：
```

不得填写虚构市场数据、CTR、销量或评估智能体分数。指出质量问题时说明原文和理由，不把个人偏好的平台或文风当硬约束。真实事实错误不能靠“待验证”标签豁免。

## 同产品资源对照重点

`milk-owned`：现有门店群、菜单/实拍素材、每天 30 分钟人力已确认。检查是否利用这些资源，并保留价格与点单入口。

`milk-unknown`：相同产品和目标，但渠道、素材、人力未知。检查是否改为有条件的计划，不能照抄已有群、已有素材或已有店员时间。

`milk-zero`：相同产品、零预算、无现有渠道/素材、每周 1 小时人力。检查是否缩小动作数量、优先低成本准备，不建议付费达人或投放。对比时同时考虑预算和人力变化，不把一切差异都归因于某一个字段。

自动对照最多证明原始资源状态传递正确、输出不同；不能证明策略更好。若三个输出仅替换资源词但没有改变行动规模和渠道取舍，应记录为质量问题。

## 证据保存

真实报告存 `artifacts/acceptance/`，不提交敏感业务资料或原始调用记录。正式反馈记录必须注明复核人身份与结果出处，不能把模型生成的“人工结论”写进报告。尚未执行本表时保持 `human_review.status=pending`、`first_stage_accepted=false`。
